我复制东西有个毛病：复制完转头就忘，等要粘贴的时候已经想不起内容放哪了。Windows 自带的剪贴板历史（Win+V）不是不能用，但我总记不住按快捷键。所以干脆写了个小工具，把历史直接挂到右键上。

ClipboardHistory 是一个跑在系统托盘里的 Windows 程序，C#/.NET 8 + WPF 写的。平时它安静地监听剪贴板：文本、图片、文件路径都会记录，默认保留最近 10 条，重复内容自动去重，密码框里复制的不会记。数据存在 `%LOCALAPPDATA%\ClipboardHistory` 下，一个 JSON 索引加一个图片目录，重启不丢。

在任意输入框上点右键，历史面板就会出现在系统菜单旁边。面板是个不抢焦点的无边框窗口，点击某条历史，内容写回剪贴板，再模拟一次 Ctrl+V，焦点始终留在原来的输入框里。

实现上就是几个系统 API 的组合：WM_CLIPBOARDUPDATE 监听剪贴板变化，低级鼠标钩子接住右键，UI Automation 判断光标下是不是输入框。代码按 TDD 写的，存储、解析、粘贴这些核心逻辑都有单元测试，一共 47 个。

开发中遇到两个坑，记一下。

浮窗位置。最初放在光标上方，右键菜单一弹出来就把它盖住。后来改成先测量系统菜单的真实位置，菜单左边放不下就放右边，基本不再重叠。游戏里也做了抑制：全屏窗口和 Unity、Unreal、SDL 这类游戏窗口内右键不弹，免得打游戏误触。

发布体积。一开始图省事用 self-contained 发布，单文件 150MB，太离谱。现在拆成两种：依赖本机 .NET 8 运行时的只有 203KB，日常自己用；压缩过的自包含便携版 65MB，拷给别人不用装环境。

已知限制：管理员权限的窗口弹不出浮窗，普通权限的程序碰不到；超过 10MB 的图片不记录；个别安全软件会拦键盘注入，这时程序会退到 UIA 或 WM_PASTE，但也不是所有程序都吃这一套。

代码开源在 GitHub：[xzrdmm/clipboard-history](https://github.com/xzrdmm/clipboard-history)。想加搜索、固定条目或者自定义热键，都欢迎提 PR。
